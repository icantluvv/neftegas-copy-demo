# sidebar-nav-icons

## Why

Пункты навигации в сайдбаре (`SidebarNav`) отображались только текстовыми
лейблами без визуальных якорей, что затрудняло быстрое сканирование меню.
Добавление иконок к каждому пункту — точечная UX-правка, не связанная с
конкретной продуктовой фичей и не затрагивающая наблюдаемое поведение
навигации (переходы по ссылкам, доступность пунктов по ролям остаются
прежними).

## What Changes

- В `NavItem` (`apps/frontend/app/(private)/constants.ts`) добавлено
  обязательное поле `icon: LucideIcon`; каждому существующему пункту
  `navItems` назначена иконка (`LayoutDashboard`, `FilePlus`, `Bell`).
- В `SidebarNav` (`apps/frontend/src/components/sidebar-nav/sidebar-nav.tsx`)
  иконка пункта рендерится перед лейблом; попутно выровнен размер кнопки
  выхода (`size-12`) под высоту пунктов меню.
- Требования к навигации (доступность пунктов по ролям, переходы, активное
  состояние) не изменились — capability не создаётся и не модифицируется.

## Capabilities

Краткое техническое изменение: наблюдаемое поведение навигации и
API-контракт не меняются, изменяется только визуальное представление
пунктов сайдбара. Delta specs не создаются (`skip_specs: true`).
