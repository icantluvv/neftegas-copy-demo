## Why

В приватном контуре (`apps/frontend/app/(private)/layout.tsx`) сейчас нет постоянной навигации: layout рендерит только `children`. Пользователю негде переключаться между разделами и негде выйти из аккаунта, кроме прямого перехода по URL.

## What Changes

- В `PrivateLayout` добавляется боковая панель навигации слева от контента, шириной 1/5 ширины экрана на десктопе, с тёмно-синим фоном и белым текстом.
- Сайдбар содержит список ссылок навигации по разделам приватного контура (на данный момент — «Дашборд», `/dashboard`).
- Внизу сайдбара — кнопка «Выйти», которая вызывает `POST /auth/logout` (существующий эндпоинт, хук `useLogout`) и после успешного выхода перенаправляет на `/login`.
- Основной контент (`children`) занимает оставшиеся 4/5 ширины экрана справа от сайдбара на десктопе.
- На мобильных экранах сайдбар скрыт по умолчанию; вверху слева отображается кнопка-бургер, по нажатию на которую сайдбар открывается поверх контента на всю ширину экрана.

## Capabilities

### New Capabilities

- `private-navigation`: боковая навигация приватного контура — состав пунктов меню, раскладка (1/5 ширины на десктопе, скрытый сайдбар и бургер-меню на мобильных экранах), выход из аккаунта через кнопку в сайдбаре.

### Modified Capabilities

_(нет)_

## Impact

- **Frontend**: `apps/frontend/app/(private)/layout.tsx` (добавление сайдбара), новый компонент сайдбара (например, `apps/frontend/app/(private)/components/sidebar-nav.tsx` или аналогичный путь по конвенции проекта). Используется существующий `useLogout` из `packages/api/base/codegen/hooks/authController/useLogout.ts`.
- **Backend**: не затрагивается — используется уже существующий эндпоинт `/auth/logout`.
- **API-контракт**: не затрагивается — новых эндпоинтов не требуется.
- Затронутых внешних зависимостей нет.
