# auth-login-background

## Why

Экран входа (`app/(public)/page.tsx`) был голым — центрированная форма без
какого-либо фирменного оформления. Пользователь попросил добавить
декоративный фон по мотивам сайта filial-организации (chmng.ru): диагональные
геометрические плоскости и волнистые линии в синих тонах. Точечная UX/бренд-
правка, не затрагивающая наблюдаемое поведение входа (валидация формы,
переходы после логина остаются прежними).

## What Changes

- Новый компонент `AuthWaveBackground`
  (`apps/frontend/src/components/auth-wave-background/`) — декоративный
  SVG-фон (диагональные плоскости + волнистые линии, `aria-hidden`,
  `pointer-events-none`), цвет — отдельный акцентный синий тон, не завязанный
  на серую тему остального приложения; лёгкий бесконечный дрейф волн
  (`@keyframes wave-drift` в `app/globals.css`).
- `app/(public)/page.tsx` — фон подключён только на экране входа (не
  затрагивает авторизованную часть приложения с таблицами/дашбордами);
  добавлен заголовок с названием приложения (`NEXT_PUBLIC_APP_NAME`) над
  формой.
- `login-form.tsx` — добавлен непрозрачный фон карточки (`bg-card`,
  `shadow-sm`), чтобы форма не сливалась с волнами фона.
- Поведение формы входа (валидация, обработка ошибок, переход после логина)
  не изменилось — capability не создаётся и не модифицируется.
