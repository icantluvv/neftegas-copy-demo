## Purpose

Уведомляет пользователя о новых непрочитанных внутрисистемных уведомлениях
системным (ОС) всплывающим уведомлением, не требуя, чтобы вкладка приложения
была в фокусе — достаточно, чтобы она была открыта.

## ADDED Requirements

### Requirement: Разрешение на системные уведомления

Система SHALL запрашивать у браузера разрешение на показ системных
уведомлений при первом монтировании приватного контура, если разрешение ещё
не запрошено (`Notification.permission === "default"`). Система SHALL NOT
запрашивать разрешение повторно, если пользователь уже дал или отклонил его.

#### Scenario: Запрос разрешения при первом посещении

- **GIVEN** пользователь открывает приложение в браузере впервые (разрешение на уведомления ещё не запрошено)
- **WHEN** приватный контур загружается
- **THEN** браузер показывает пользователю системный запрос разрешения на уведомления

### Requirement: Системное уведомление о новом непрочитанном сообщении

Система SHALL показывать системное уведомление ОС для каждой записи, которая
стала непрочитанной и не входила в число уведомлений, известных на предыдущем
опросе `GET /notifications`, при условии, что пользователь дал разрешение на
уведомления. Система SHALL NOT показывать системное уведомление для записей,
уже присутствовавших при первой загрузке страницы.

#### Scenario: Новое уведомление показывается системным всплытием

- **GIVEN** пользователь дал разрешение на уведомления
- **AND** страница уже выполнила первый опрос `GET /notifications`
- **WHEN** очередной фоновый опрос обнаруживает новую непрочитанную запись, отсутствовавшую на предыдущем опросе
- **THEN** система показывает системное уведомление ОС с текстом этой записи

#### Scenario: Уведомления, существовавшие при загрузке страницы, не показываются повторно

- **GIVEN** у пользователя уже есть непрочитанные уведомления на момент открытия страницы
- **WHEN** страница выполняет первый опрос `GET /notifications`
- **THEN** система не показывает системные уведомления по этим уже существующим записям

### Requirement: Переход по клику на системное уведомление

Клик по системному уведомлению SHALL переводить фокус на вкладку приложения,
помечать соответствующую запись прочитанной и переводить пользователя на
карточку связанной корректировки.

#### Scenario: Клик по системному уведомлению открывает корректировку

- **GIVEN** показано системное уведомление о возврате корректировки COR-000002
- **WHEN** пользователь кликает по этому системному уведомлению
- **THEN** система переводит фокус на вкладку приложения
- **AND** помечает уведомление прочитанным
- **AND** переходит на маршрут `/corrections/COR-000002`
