## MODIFIED Requirements

### Requirement: Пометка прочитанным при переходе на карточку корректировки из интерфейса

Система SHALL NOT изменять статус прочитанности уведомления при открытии
выпадающей панели без клика по конкретной записи. Система SHALL
автоматически помечать прочитанными все уведомления текущего пользователя,
связанные с корректировкой, в момент перехода на карточку этой корректировки
(`/corrections/{humanId}`) по клику на элементе интерфейса, ведущем на эту
карточку — клик по записи уведомления (в панели или на странице
`/notifications`) либо клик по кнопке «Открыть» в обзорной таблице
дашборда. Система SHALL NOT помечать уведомления прочитанными при заходе на
карточку в обход перечисленных элементов интерфейса (прямой ввод URL,
переход по внешней ссылке, навигация назад/вперёд, обновление уже открытой
страницы) — запрос на пометку привязан к действию перехода, а не к факту
отображения карточки.

#### Scenario: Открытие панели не меняет статус прочитанности
- **GIVEN** у пользователя есть непрочитанные уведомления
- **WHEN** пользователь открывает выпадающую панель, не кликая ни по одной записи
- **THEN** все уведомления сохраняют прежний статус прочитанности

#### Scenario: Клик по кнопке «Открыть» в дашборде помечает связанные уведомления прочитанными
- **GIVEN** у пользователя есть непрочитанное уведомление, связанное с корректировкой COR-000003
- **WHEN** пользователь кликает по кнопке «Открыть» в обзорной таблице дашборда для COR-000003
- **THEN** уведомление, связанное с COR-000003, становится прочитанным
- **AND** бейдж непрочитанных на колокольчике уменьшается на число таких уведомлений

#### Scenario: Открытие карточки через клик по уведомлению помечает все связанные уведомления прочитанными
- **GIVEN** пользователь кликает по непрочитанному уведомлению, связанному с корректировкой COR-000002
- **WHEN** система переходит на карточку COR-000002
- **THEN** все уведомления текущего пользователя, связанные с COR-000002, становятся прочитанными

#### Scenario: Обновление уже открытой карточки не отправляет повторный запрос на пометку
- **GIVEN** пользователь уже открыл карточку COR-000004 через клик по уведомлению, и все связанные уведомления помечены прочитанными
- **WHEN** пользователь обновляет страницу карточки (F5) или заходит на неё повторно по прямой ссылке
- **THEN** запрос на пометку уведомлений прочитанными не отправляется
