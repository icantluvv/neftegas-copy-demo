## MODIFIED Requirements

### Requirement: Пометка прочитанным при открытии панели и карточки корректировки

Система SHALL NOT изменять статус прочитанности уведомления при открытии
выпадающей панели без клика по конкретной записи. Система SHALL
автоматически помечать прочитанными все уведомления текущего пользователя,
связанные с корректировкой, в момент открытия карточки этой корректировки
(`/corrections/{humanId}`) — независимо от того, попал ли пользователь на
карточку через клик по уведомлению (в панели или на странице
`/notifications`) или напрямую, в обход списка уведомлений.

#### Scenario: Открытие панели не меняет статус прочитанности
- **GIVEN** у пользователя есть непрочитанные уведомления
- **WHEN** пользователь открывает выпадающую панель, не кликая ни по одной записи
- **THEN** все уведомления сохраняют прежний статус прочитанности

#### Scenario: Открытие карточки корректировки напрямую помечает связанные уведомления прочитанными
- **GIVEN** у пользователя есть непрочитанное уведомление, связанное с корректировкой COR-000003
- **WHEN** пользователь открывает страницу корректировки COR-000003 не через уведомление
- **THEN** уведомление, связанное с COR-000003, становится прочитанным
- **AND** бейдж непрочитанных на колокольчике уменьшается на число таких уведомлений

#### Scenario: Открытие карточки через клик по уведомлению помечает его прочитанным тем же способом
- **GIVEN** пользователь кликает по непрочитанному уведомлению, связанному с корректировкой COR-000002
- **WHEN** система переходит на карточку COR-000002
- **THEN** все уведомления текущего пользователя, связанные с COR-000002, становятся прочитанными
