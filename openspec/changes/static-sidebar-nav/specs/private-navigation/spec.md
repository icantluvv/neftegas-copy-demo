## MODIFIED Requirements

### Requirement: Пункты меню навигации в сайдбаре

Система SHALL отображать в боковой панели фиксированный набор пунктов навигации по разделам продукта. Состав пунктов и их целевые маршруты SHALL быть одинаковыми на всех страницах приватного контура и SHALL НЕ зависеть от текущего маршрута. Видимость отдельного пункта MAY зависеть только от роли пользователя.

Набор пунктов:
- «Рабочий стол» → `/dashboard`
- «План на 2027» → `/planning`
- «Выполнение» → `/execution`
- «Факт» → `/fact`
- «Создать корректировку» → `/corrections/create` — только для роли `FILIAL`
- «Уведомления» → `/notifications`

Система SHALL НЕ отображать отдельную навигацию по разделам вне боковой панели (верхних вкладок/табов быть не должно).

#### Scenario: Переход по пункту «Рабочий стол»
- **GIVEN** авторизованный пользователь находится на странице приватного контура
- **WHEN** пользователь нажимает пункт меню «Рабочий стол»
- **THEN** система переходит на маршрут `/dashboard`

#### Scenario: Переход по пункту «Уведомления»
- **GIVEN** авторизованный пользователь находится на странице приватного контура
- **WHEN** пользователь нажимает пункт меню «Уведомления»
- **THEN** система переходит на маршрут `/notifications`

#### Scenario: Состав пунктов не зависит от текущей страницы
- **GIVEN** авторизованный пользователь с ролью `FILIAL`
- **WHEN** пользователь открывает `/planning` (или любой другой приватный маршрут)
- **THEN** в боковой панели отображаются те же пункты и с теми же ссылками, что и на `/dashboard`: «Рабочий стол» → `/dashboard`, «Уведомления» → `/notifications`, «Создать корректировку» → `/corrections/create`

#### Scenario: «Создать корректировку» виден только роли «Филиал»
- **GIVEN** авторизован пользователь с ролью `FILIAL`
- **WHEN** пользователь открывает любую страницу приватного контура
- **THEN** в боковой панели отображается пункт «Создать корректировку» со ссылкой на `/corrections/create`

#### Scenario: «Создать корректировку» скрыт для остальных ролей
- **GIVEN** авторизован пользователь с ролью `CFO` или `DTOE`
- **WHEN** пользователь открывает любую страницу приватного контура
- **THEN** пункт «Создать корректировку» в боковой панели не отображается

## ADDED Requirements

### Requirement: Подсветка активного пункта навигации

Система SHALL визуально подсвечивать в боковой панели пункт, соответствующий текущему маршруту. Пункт считается активным, если текущий путь точно совпадает с его целевым маршрутом либо начинается с одного из связанных с пунктом префиксов. Подсветка SHALL быть единственным аспектом навигации, зависящим от текущего маршрута.

#### Scenario: Подсветка по точному совпадению маршрута
- **GIVEN** авторизованный пользователь открывает `/notifications`
- **THEN** пункт «Уведомления» в боковой панели отображается как активный

#### Scenario: Подсветка по префиксу вложенного маршрута
- **GIVEN** авторизованный пользователь открывает страницу вида `/corrections/COR-000001`
- **THEN** пункт «Рабочий стол» в боковой панели отображается как активный

#### Scenario: Неактивные пункты не подсвечены
- **GIVEN** авторизованный пользователь открывает `/planning`
- **THEN** пункт «План на 2027» отображается как активный
- **AND** остальные пункты боковой панели отображаются как неактивные
