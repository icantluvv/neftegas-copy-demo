## ADDED Requirements

### Requirement: Брендинг в верхней части сайдбара

Система SHALL отображать в верхней части боковой панели навигации круглый логотип-плейсхолдер без изображения и название компании «Черноморнефтегаз».

#### Scenario: Брендинг виден на приватной странице
- **WHEN** авторизованный пользователь открывает любую страницу приватного контура
- **THEN** в верхней части боковой панели отображается круглый логотип-плейсхолдер без изображения
- **AND** рядом с логотипом отображается название «Черноморнефтегаз»

### Requirement: Пункты меню навигации в сайдбаре

Система SHALL отображать в боковой панели пункты меню «Рабочий стол» (ссылка на `/dashboard`) и «Уведомления» (ссылка на `/notifications`).

#### Scenario: Переход по пункту «Рабочий стол»
- **GIVEN** авторизованный пользователь находится на странице приватного контура
- **WHEN** пользователь нажимает пункт меню «Рабочий стол»
- **THEN** система переходит на маршрут `/dashboard`

#### Scenario: Переход по пункту «Уведомления»
- **GIVEN** авторизованный пользователь находится на странице приватного контура
- **WHEN** пользователь нажимает пункт меню «Уведомления»
- **THEN** система переходит на маршрут `/notifications`

### Requirement: Блок профиля пользователя в нижней части сайдбара

Система SHALL отображать в нижней части боковой панели, над кнопкой «Выйти», блок профиля текущего пользователя: круглый аватар-плейсхолдер с инициалами и полное ФИО. Данные пользователя SHALL поступать в блок профиля из серверной SSR-сессии, а не из отдельного клиентского запроса.

#### Scenario: Блок профиля отображает данные текущего пользователя
- **GIVEN** авторизован пользователь с ФИО «Иванов Иван Иванович»
- **WHEN** пользователь открывает любую страницу приватного контура
- **THEN** в нижней части боковой панели отображается круглый аватар-плейсхолдер с инициалами пользователя
- **AND** рядом с аватаром отображается полное ФИО «Иванов Иван Иванович»

#### Scenario: Блок профиля не выполняет отдельный запрос данных пользователя
- **GIVEN** авторизованный пользователь открывает страницу приватного контура
- **WHEN** страница отрисовывается
- **THEN** данные для блока профиля берутся из результата серверного запроса сессии, уже выполненного при рендере страницы
- **AND** боковая панель не отправляет собственный клиентский запрос за данными пользователя
