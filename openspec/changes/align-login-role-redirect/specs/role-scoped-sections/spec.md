## Purpose

Ограничивает доступ к ролевым разделам приватного контура (`/filial`, `/cfo`,
`/dtoe`) только пользователями с соответствующей ролью и даёт понятную обратную
связь при попытке прямого захода в чужой раздел.

## ADDED Requirements

### Requirement: Доступ к ролевому разделу только для соответствующей роли

Система SHALL разрешать доступ к разделу `/filial` только пользователям с ролью
`FILIAL`, к разделу `/cfo` — только пользователям с ролью `CFO`, к разделу
`/dtoe` — только пользователям с ролью `DTOE`.

#### Scenario: Пользователь открывает свой раздел
- **GIVEN** авторизован пользователь с ролью `CFO`
- **WHEN** пользователь открывает `/cfo`
- **THEN** система отображает содержимое раздела `/cfo`

#### Scenario: Пользователь открывает чужой раздел напрямую
- **GIVEN** авторизован пользователь с ролью `CFO`
- **WHEN** пользователь открывает `/dtoe` напрямую по URL
- **THEN** бэкенд отвечает `403 Forbidden` на запрос данных раздела `/dtoe`
- **AND** фронтенд отображает пользователю экран «Доступ запрещён» вместо содержимого раздела

#### Scenario: Неавторизованный пользователь пытается открыть ролевой раздел
- **GIVEN** пользователь не аутентифицирован
- **WHEN** пользователь открывает любой из разделов `/filial`, `/cfo`, `/dtoe`
- **THEN** система перенаправляет пользователя на экран входа
