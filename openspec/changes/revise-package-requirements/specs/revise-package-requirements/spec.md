## ADDED Requirements

### Requirement: Состав обязательного пакета документов

Система SHALL требовать для типа корректировки «Стандартная корректировка»
следующий состав пакета: «Excel корректировка» (основной слот), «Согласованная
служебная записка», «Пакет обосновывающих документов», и группу «Перечень
комплекта МТР (ХС)» из двух альтернативных вариантов — «Локальный сметный
расчёт (ПД)» и «ХЗ-х ТКП».

#### Scenario: Создание корректировки формирует новый состав слотов

GIVEN тип корректировки «Стандартная корректировка»
WHEN пользователь создаёт корректировку (`POST /corrections`)
THEN создаётся слот «Excel корректировка» (основной)
AND создаётся слот «Согласованная служебная записка»
AND создаётся слот «Пакет обосновывающих документов»
AND создаётся слот «Локальный сметный расчёт (ПД)»
AND создаётся слот «ХЗ-х ТКП»

### Requirement: Комплектность группы «выбор одного из альтернативных требований»

Система SHALL считать группу требований с общим `choiceGroupKey` выполненной,
если хотя бы один слот этой группы содержит ≥1 версию файла. Система SHALL NOT
требовать заполнения всех слотов группы одновременно. Направление
корректировки (`POST /corrections/{humanId}/send`) SHALL быть заблокировано
(`400`), пока ни один слот группы не заполнен и группа обязательна.

#### Scenario: Ни один вариант группы не заполнен — пакет неполон

GIVEN корректировка типа «Стандартная корректировка» в статусе `DRAFT`
AND слоты «Локальный сметный расчёт (ПД)» и «ХЗ-х ТКП» оба без версий файла
AND все остальные обязательные слоты заполнены
WHEN пользователь отправляет `POST .../send`
THEN сервер отвечает `400`
AND сообщение об ошибке включает «Перечень комплекта МТР (ХС)»

#### Scenario: Заполнен один из двух вариантов — пакет полон

GIVEN корректировка типа «Стандартная корректировка» в статусе `DRAFT`
AND слот «Локальный сметный расчёт (ПД)» содержит версию файла
AND слот «ХЗ-х ТКП» без версий файла
AND все остальные обязательные слоты заполнены
WHEN пользователь отправляет `POST .../send`
THEN направление проходит успешно
AND статус корректировки становится `UNDER_CFO_REVIEW`

#### Scenario: Заполнены оба варианта — пакет полон

GIVEN корректировка типа «Стандартная корректировка» в статусе `DRAFT`
AND слоты «Локальный сметный расчёт (ПД)» и «ХЗ-х ТКП» оба содержат версию
файла
AND все остальные обязательные слоты заполнены
WHEN пользователь отправляет `POST .../send`
THEN направление проходит успешно
