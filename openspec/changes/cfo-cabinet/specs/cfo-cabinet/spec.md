## Purpose

Даёт роли «ЦФО» обзор направленных ему корректировок на `/dashboard` (плитки
статистики, распределение по статусу СВОЕГО ЦФО, фильтры по статусу и по филиалу,
таблица), закрывая задачу 1 из ЧТЗ «Кабинет ЦФО» (`docs/tz/cfo-cabinet.md`).

## ADDED Requirements

### Requirement: Плитки статистики на дашборде ЦФО

Система SHALL отображать на `/dashboard` для роли CFO 4 плитки статистики —
«Всего направлено», «На проверке у нас», «Мы вернули», «Мы согласовали» — с
данными из `GET /corrections/stats/cfo`. Плитка «На проверке у нас» SHALL
отображать значение жёлтым цветом, плитка «Мы вернули» SHALL отображать значение
красным цветом, плитка «Мы согласовали» SHALL отображать значение зелёным цветом.

#### Scenario: Плитки показывают статистику ЦФО

- **GIVEN** авторизован пользователь роли CFO
- **WHEN** пользователь открывает `/dashboard`
- **THEN** система отображает 4 плитки: «Всего направлено», «На проверке у нас», «Мы вернули», «Мы согласовали»
- **AND** значение плитки «На проверке у нас» отображается жёлтым цветом
- **AND** значение плитки «Мы вернули» отображается красным цветом
- **AND** значение плитки «Мы согласовали» отображается зелёным цветом

### Requirement: Распределение корректировок по статусу ЦФО на дашборде

Система SHALL отображать на `/dashboard` для роли CFO донат-график распределения
направленных этому ЦФО корректировок по статусу СОБСТВЕННОГО решения этого ЦФО
(«На проверке у нас» — `PENDING`, «Мы вернули» — `RETURNED`, «Мы согласовали» —
`APPROVED`), а не по общему статусу корректировки — с легендой (цвет, название
группы, число) и общим числом в центре графика.

#### Scenario: График показывает 3 группы с числом каждой

- **GIVEN** у ЦФО есть направленные корректировки в разных статусах решения этого ЦФО
- **WHEN** пользователь открывает `/dashboard`
- **THEN** система отображает донат-график с сегментами «На проверке у нас», «Мы вернули», «Мы согласовали»
- **AND** легенда показывает название каждой группы и число корректировок в ней
- **AND** в центре графика отображается общее число направленных этому ЦФО корректировок

### Requirement: Независимые фильтры таблицы корректировок ЦФО по статусу и по филиалу

Система SHALL предоставлять на `/dashboard` для роли CFO два независимых
выпадающих списка — «Фильтр по статусу ЦФО» (значения по умолчанию «— все статусы
—» и три статуса из Requirement «Распределение корректировок по статусу ЦФО на
дашборде») и «Фильтр по филиалу» (значение по умолчанию «Все филиалы» и список
филиалов, представленных в списке направленных этому ЦФО корректировок) —
ограничивающих таблицу корректировок пересечением обоих условий без нового
запроса к серверу. Клик по сегменту графика или строке легенды SHALL
устанавливать соответствующее значение в фильтре статуса, не изменяя фильтр по
филиалу; повторный клик по тому же сегменту SHALL возвращать фильтр статуса к
значению «— все статусы —».

#### Scenario: Выбор статуса в фильтре сужает таблицу

- **GIVEN** у ЦФО есть корректировки в статусе решения ЦФО «Ожидает» и «Возвращено»
- **WHEN** пользователь выбирает в фильтре статуса значение «Мы вернули»
- **THEN** таблица показывает только корректировки со статусом ЦФО «Возвращено»

#### Scenario: Выбор филиала в фильтре сужает таблицу независимо от статуса

- **GIVEN** у ЦФО есть направленные корректировки от двух разных филиалов
- **WHEN** пользователь выбирает в фильтре филиала конкретный филиал
- **THEN** таблица показывает только корректировки этого филиала
- **AND** ранее выбранный фильтр по статусу ЦФО остаётся применённым

#### Scenario: Клик по сегменту графика выставляет фильтр статуса

- **GIVEN** пользователь находится на `/dashboard`
- **WHEN** пользователь кликает по сегменту «Мы согласовали» на графике
- **THEN** фильтр статуса принимает значение «Мы согласовали»
- **AND** таблица показывает только корректировки этой группы

#### Scenario: Повторный клик по тому же сегменту сбрасывает фильтр статуса

- **GIVEN** фильтр статуса установлен в значение «Мы вернули» кликом по сегменту графика
- **WHEN** пользователь повторно кликает по тому же сегменту «Мы вернули»
- **THEN** фильтр статуса возвращается к значению «— все статусы —»

### Requirement: Таблица «Направленные корректировки» на дашборде ЦФО

Система SHALL отображать на `/dashboard` для роли CFO таблицу корректировок,
направленных этому ЦФО, с колонками «ID», «Филиал», «Тип», «Статус пакета»
(цветной бейдж общего статуса корректировки), «Статус ЦФО» (цветной бейдж статуса
решения именно этого ЦФО), «Изменено» и кнопкой «Открыть» в каждой строке,
переводящей на карточку `/corrections/{humanId}`. При отсутствии направленных
корректировок SHALL отображаться вместо графика, фильтров и таблицы текст о
пустом состоянии.

#### Scenario: Таблица показывает список направленных корректировок

- **GIVEN** этому ЦФО направлены 2 корректировки от разных филиалов
- **WHEN** пользователь роли CFO открывает `/dashboard`
- **THEN** таблица показывает обе корректировки с колонками ID, Филиал, Тип, Статус пакета, Статус ЦФО, Изменено
- **AND** каждая строка содержит кнопку «Открыть»

#### Scenario: Статус пакета и статус ЦФО могут отличаться в одной строке

- **GIVEN** корректировка направлена двум ЦФО, и текущий ЦФО уже согласовал, а второй ЦФО ещё нет
- **WHEN** пользователь роли CFO (текущий ЦФО) открывает `/dashboard`
- **THEN** колонка «Статус пакета» показывает общий статус корректировки (не финальный)
- **AND** колонка «Статус ЦФО» показывает «Согласовано» для текущего ЦФО

#### Scenario: Кнопка «Открыть» переходит на карточку корректировки

- **GIVEN** в таблице есть корректировка COR-000003
- **WHEN** пользователь нажимает «Открыть» в строке COR-000003
- **THEN** система переходит на маршрут `/corrections/COR-000003`

#### Scenario: Пустое состояние при отсутствии направленных корректировок

- **GIVEN** этому ЦФО не направлено ни одной корректировки
- **WHEN** пользователь роли CFO открывает `/dashboard`
- **THEN** система отображает текст о пустом состоянии вместо графика, фильтров и таблицы
