## Purpose

Даёт пользователю приватного контура постоянную боковую навигацию по разделам продукта и понятный способ выйти из аккаунта.

## ADDED Requirements

### Requirement: Боковая навигация приватного контура

Система SHALL отображать в приватном контуре боковую панель навигации слева от основного контента на всех страницах группы маршрутов `(private)`.

#### Scenario: Сайдбар виден на приватной странице
- **WHEN** авторизованный пользователь открывает любую страницу приватного контура (например, `/dashboard`)
- **THEN** система отображает боковую панель навигации слева от контента страницы

#### Scenario: Раскладка ширины на десктопе
- **WHEN** приватная страница отображается на экране десктопной ширины
- **THEN** боковая панель занимает 1/5 ширины экрана
- **AND** основной контент занимает оставшиеся 4/5 ширины экрана справа от панели

### Requirement: Адаптивное поведение сайдбара на мобильных экранах

Система SHALL скрывать боковую панель по умолчанию на экранах мобильной ширины и SHALL предоставлять кнопку-бургер в левом верхнем углу для её открытия.

#### Scenario: Сайдбар скрыт на мобильном экране по умолчанию
- **WHEN** авторизованный пользователь открывает приватную страницу на экране мобильной ширины
- **THEN** боковая панель навигации не отображается
- **AND** в левом верхнем углу отображается кнопка-бургер

#### Scenario: Открытие сайдбара по кнопке-бургеру на мобильном экране
- **GIVEN** пользователь находится на приватной странице на экране мобильной ширины
- **AND** боковая панель скрыта
- **WHEN** пользователь нажимает кнопку-бургер
- **THEN** боковая панель открывается поверх контента на всю ширину экрана

#### Scenario: Закрытие сайдбара на мобильном экране по кнопке-бургеру
- **GIVEN** пользователь находится на приватной странице на экране мобильной ширины
- **AND** боковая панель открыта
- **WHEN** пользователь повторно нажимает кнопку-бургер
- **THEN** боковая панель закрывается

#### Scenario: Закрытие сайдбара на мобильном экране по выбору пункта меню
- **GIVEN** пользователь находится на приватной странице на экране мобильной ширины
- **AND** боковая панель открыта
- **WHEN** пользователь нажимает на пункт навигации в сайдбаре
- **THEN** система переходит на выбранный маршрут
- **AND** боковая панель закрывается

### Requirement: Выход из аккаунта через сайдбар

Система SHALL предоставлять в нижней части боковой панели кнопку «Выйти», по нажатию на которую пользователь выходит из аккаунта.

#### Scenario: Успешный выход
- **GIVEN** авторизованный пользователь находится на странице приватного контура
- **WHEN** пользователь нажимает кнопку «Выйти» в сайдбаре
- **THEN** система отправляет запрос на выход (`POST /auth/logout`)
- **AND** после успешного ответа система перенаправляет пользователя на страницу `/login`

#### Scenario: Ошибка при выходе
- **GIVEN** авторизованный пользователь находится на странице приватного контура
- **WHEN** пользователь нажимает кнопку «Выйти» и запрос на выход завершается ошибкой
- **THEN** система показывает пользователю уведомление об ошибке
- **AND** пользователь остаётся на текущей странице приватного контура
