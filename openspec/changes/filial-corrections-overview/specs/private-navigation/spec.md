## MODIFIED Requirements

### Requirement: Пункты меню навигации в сайдбаре

Система SHALL отображать в боковой панели пункты меню «Рабочий стол» (ссылка
на `/dashboard`) и «Уведомления» (ссылка на `/notifications`), видимые всем
авторизованным ролям. Система SHALL дополнительно отображать пункт «Создать
корректировку» (ссылка на `/corrections/create`), видимый только роли FILIAL.

#### Scenario: Переход по пункту «Рабочий стол»
- **GIVEN** авторизованный пользователь находится на странице приватного контура
- **WHEN** пользователь нажимает пункт меню «Рабочий стол»
- **THEN** система переходит на маршрут `/dashboard`

#### Scenario: Переход по пункту «Уведомления»
- **GIVEN** авторизованный пользователь находится на странице приватного контура
- **WHEN** пользователь нажимает пункт меню «Уведомления»
- **THEN** система переходит на маршрут `/notifications`

#### Scenario: Пункт «Создать корректировку» виден роли FILIAL

- **GIVEN** авторизован пользователь роли FILIAL
- **WHEN** пользователь открывает страницу приватного контура
- **THEN** в боковой панели отображается пункт меню «Создать корректировку»
- **WHEN** пользователь нажимает пункт «Создать корректировку»
- **THEN** система переходит на маршрут `/corrections/create`

#### Scenario: Пункт «Создать корректировку» не виден ролям ЦФО и ДТОиР

- **GIVEN** авторизован пользователь роли CFO или DTOE
- **WHEN** пользователь открывает страницу приватного контура
- **THEN** в боковой панели нет пункта меню «Создать корректировку»
